# 🚀 JobRadar

JobRadar is a full-stack job aggregation platform that collects jobs from multiple sources and provides search, filtering, sorting, pagination, and detailed job views.

## ✨ Features

* Job aggregation from **Adzuna & Remotive**
* Search jobs by title/company/description
* Location, source & job type filters
* Newest/oldest sorting
* Pagination
* Job details with skills, salary & description
* Direct link to original job posting
* Responsive UI

## 🛠️ Tech Stack

**Frontend:** React, TypeScript, Vite, React Router, CSS

**Backend:** Node.js, Express.js, TypeScript, PostgreSQL

**APIs:** Adzuna, Remotive

## ▶️ Run Locally

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend: `http://localhost:5173`

Backend: `http://localhost:4000`
